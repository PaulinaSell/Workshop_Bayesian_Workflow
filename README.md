# Workshop on Bayesian Workflow

Here you can find materials for a two-day workshop on *Bayesian Workflow* held on 26-27 November 2026 at Karolinska Institutet.
The workshop was organised and held by Simon Steiger, Frida Smids, Younes Laalou and Paulina Sell.

For a brief overview, see [here](https://learnbayes.se/events_2026/workflow_workshop/ad.pdf).

Find more events and resources on [our website](https://learnbayes.se).

## Overview
- `Workshop.html` - Notebook of most things we covered during the workshop, *written for beginners*.
- `workshop.qmd` - Quarto file for the notebook. Download and play around! (`rethinking` package required).
- `R_code/` - R code to simulate a dataset on air pollution and blood pressure and a simple Bayesian model to analyse it.
- `data/` - simulated dataset on air pollution and blood pressure ready to download (.csv).
